# 2048 合并挑战 · 微信小游戏

一款可直接发布上线的微信小游戏：经典 2048 数字合并玩法，纯 Canvas 绘制，**零图片素材、零第三方依赖**，主包仅约 30KB（限制为 4MB）。

**已实现**

- 完整玩法闭环：滑动移动 / 合并翻倍 / 计分 / 最高分持久化 / 进度存档（退出重开继续玩）
- 滑动 + 合并双阶段动画、得分飘字、胜利（达成 2048）与失败弹窗、继续挑战模式
- WebAudio 实时合成音效（无音频文件）、合并震动反馈、静音开关
- 微信能力：`wx.shareAppMessage` 主动分享成绩、右上角菜单转发文案
- **广告系统**：「看广告复活」——默认照片广告（自定义素材，开箱即用），配置微信广告位后自动切换为真实激励视频
- 刘海屏/安全区适配、多分辨率自适应、触控判定
- 网页版预览（与小游戏共用同一份代码）+ 21 项核心逻辑单元测试

> 玩法机制致敬原版 [2048](https://play2048.co/)（Gabriele Cirulli，MIT 协议），本项目全部界面为 Canvas 原创绘制。

## 项目结构

```
D:\微信小游戏
├── game.js               # 小游戏入口（微信开发者工具从这里启动）
├── game.json             # 小游戏配置（竖屏）
├── project.config.json   # 项目配置（appid 在这里替换）
├── js/
│   ├── core.js           # 核心玩法逻辑（纯逻辑，无平台依赖，可单测）
│   ├── render.js         # Canvas 渲染：布局、方块配色、动画、弹窗、toast
│   ├── main.js           # 主循环、触摸输入、动画调度、分享、存档、广告流程
│   ├── ad.js             # 激励视频广告封装（wx.createRewardedVideoAd）
│   ├── storage.js        # wx 本地存储封装（最高分/存档/静音）
│   └── sound.js          # WebAudio 合成音效
├── test/
│   └── core.test.js      # 核心逻辑单元测试（Node 环境）
├── web-preview/          # 浏览器预览（wx 适配层 + 模块加载器），不参与上传
└── README.md
```

`web-preview/`、`test/`、`README.md` 已在 `project.config.json` 的 `packOptions.ignore` 中排除，**不会被打进小游戏包**。

## 本地试玩

### 方式一：浏览器（无需安装微信开发者工具）

任意静态服务器指向本项目目录即可，例如（已装 Python 时）：

```bash
python -m http.server 8899 --bind 127.0.0.1 --directory "D:\微信小游戏"
```

然后浏览器打开 <http://127.0.0.1:8899/web-preview/>。鼠标按下拖动 = 滑动操作，手机浏览器访问则直接支持触摸滑动。

### 方式二：微信开发者工具

1. 下载安装「微信开发者工具」稳定版：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 打开工具 → 「导入项目」→ 目录选择 `D:\微信小游戏` → AppID 先用「测试号」即可本地运行
3. 模拟器中试玩；点「预览」扫码可在自己手机上真机体验

### 运行单元测试（可选，需 Node.js）

```bash
node test/core.test.js
```

覆盖：四个方向移动合并、一次只合并一对、无效移动、胜负判定、存档往返、非法存档防护、生成概率。

## 正式发布到微信（重点）

### 第 0 步：确认资质（决定能不能上、怎么上）

| 你的情况 | 需要什么 |
| --- | --- |
| 免费游戏（可挂广告变现） | **不需要版号**。提审需《计算机软件著作权登记证书》（软著）+《游戏自审自查报告》 |
| 含内购（虚拟支付） | **必须版号**，另需软著、ICP 证等，且**个人主体不能开通内购**（需企业或个体工商户） |

- 软著到「中国版权保护中心」或代理机构办理，一般 1~2 个月（可加急），建议与开发同步进行。
- 个人主体现在可以注册小游戏，只是不能开通虚拟支付；企业/个体工商户主体可开通。
- 以上为微信开放社区与开发者社区整理的现行做法（2024—2026），提审前以微信官方最新指引为准：官方开发指南 <https://developers.weixin.qq.com/minigame/dev/guide/>（其中「小游戏接入指引」列出上线资质与审核资料）。

### 第 1 步：注册小游戏账号

1. 打开 <https://mp.weixin.qq.com/> → 「立即注册」→ 选「小程序」（小游戏属于小程序账号体系）
2. 按提示选择主体类型、填写邮箱并激活、完成主体信息验证（**主体信息提交后不可变更**）
3. 进入后台，「设置 → 基本设置 → 服务类目」选择 **游戏 → 休闲游戏**，按页面指引上传资质材料

### 第 2 步：填入你的 AppID

后台「管理 → 开发管理 → 开发设置」中查看 AppID，替换 `project.config.json` 中：

```json
"appid": "touristappid"   ← 替换成你的 AppID
```

### 第 3 步：完善游戏信息

- **名称**：全网唯一。纯「2048」大概率重名，建议如「合并2048·数字消除」「2048欢乐合并」等
- **头像**：建议 144×144 以上（可在网页预览里截图，或用任意制图工具制作）
- **简介**：一句话介绍玩法
- **用户隐私保护指引**：本游戏不收集任何用户信息，按指引勾选「不收集」即可

### 第 4 步：上传代码

微信开发者工具 → 打开本项目 → 右上角「上传」→ 版本号填 `1.0.0`，备注写清功能（如：2048 数字合并小游戏，含计分/存档/分享）。

### 第 5 步：提交审核 → 发布

微信公众平台 → 「版本管理」→ 开发版本 → 「提交审核」→ 审核通过后（一般 1~7 天）点「发布」。发布后用户在微信内搜索游戏名即可游玩。

### 发布前检查清单

- [ ] `project.config.json` 的 `appid` 已替换为正式 AppID
- [ ] 名称/头像/简介已设置且不与他人重名
- [ ] 服务类目为「游戏-休闲游戏」，资质材料已上传
- [ ] 真机预览：能进入游戏、滑动正常、无白屏
- [ ] （如接广告）`js/ad.js` 已填广告位 ID，真机验证「看广告复活」全流程
- [ ] （如需）广告位/内购已按要求配置资质

## 广告系统（已内置：照片广告 + 激励视频）

游戏结束弹窗内置「**看广告复活**」：看完广告后清除棋盘上数值最小的 4 个方块并继续本局（分数保留）；中途关闭不发奖励。

**广告形式（自动切换，无需手动选择）：**

| 状态 | 展示的广告 |
| --- | --- |
| 未配置微信广告位（默认） | **照片广告**：全屏展示 `assets/photo-ad.jpg` 3 秒后发奖。不需要流量主，开箱即用 |
| 已配置微信激励视频广告位 | 优先展示**真实激励视频广告**（可获广告分成） |

- **换照片**：直接替换 `assets/photo-ad.jpg`（建议竖版图片，大小控制在 1MB 内）
- **不想要照片广告、只留真实广告**：未配置广告位时按钮自动隐藏，无需处理

> ⚠️ **隐私提醒**：照片广告素材会随代码公开发布到 GitHub 和网页版，请确认照片中的当事人不介意公开露出再使用。

**接入真实激励视频（3 步，可选）：**

1. **开通流量主**：微信公众平台 → 「推广 → 流量主」。门槛为小游戏**累计独立访客（UV）≥ 1000** 且无严重违规（以后台页面显示为准）
2. **创建广告位**：「流量主 → 广告位管理 → 新建广告位」→ 选「激励视频广告」→ 复制广告位 ID
3. **填入 ID**：打开 `js/ad.js`，把 ID 填到顶部 `AD_UNIT_ID`，重新上传代码

**行为细节（`js/ad.js` 已按官方推荐处理）：**

- 只在 `onClose` 回调 `isEnded === true`（或 `undefined`）时发奖励，中途关闭不发
- `ad.show()` 失败时自动 `load()` 后重试一次
- 广告实例全局单例、启动时预创建，加快首次拉起
- 拉取失败（如无填充 errCode 1004）toast 提示「暂时没有合适的广告」，不会卡死流程

**测试提示：**

- 微信开发者工具通常拉不到真实广告（提示无填充属正常），请用**真机调试**验证
- 网页预览注入模拟广告位 ID（`__minigame2048.ad.setAdUnitId('test')`）可测试真实广告的完整交互路径

## 审核易被拒的点

1. **名称重复或含知名商标** → 换一个独特名称
2. **类目与内容不符** → 本游戏选「休闲游戏」即可
3. **内容空洞、无法进入玩法** → 本游戏功能完整，无此问题
4. **抄袭换皮嫌疑** → 2048 玩法机制属公共游戏机制，本项目界面为原创 Canvas 绘制，提交时可在备注中说明
